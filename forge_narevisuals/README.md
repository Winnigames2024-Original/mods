# NareVisuals

Клиентский мод для **Minecraft 1.21.4 / Forge 54.1.22**. Идёт в сборке
`1.21.4-ForgeVisuals` лаунчера **NareLauncher**.

Мод включается только с аргументом запуска `--visuals`. Без него он
загружается, но ничего не рисует и не меняет — игра выглядит ванильно.

## Что внутри

**Интерфейс**
- своё главное меню со звёздами, свечением у горизонта и настройкой отступов
- HUD из отдельных элементов: FPS, пинг, координаты, CPS, нажатия клавиш,
  броня, эффекты, игроки рядом, стрелка на ближайшего игрока, маркер попадания
- редактор HUD — элементы перетаскиваются мышью
- встроенный ресурспак на кнопки, поля и ползунки

**Мир**
- подсветка игроков: рамка, цвет по здоровью, полоска здоровья, имя, броня,
  расстояние
- подсветка блока под прицелом, своя заливка граней
- своё небо (пресеты или своя картинка), медленное вращение
- яркость и ночное зрение

**Камера**
- свободная камера: полёт WASD, скорость колесом, выход одной клавишей
- приближение по клавише
- свой прицел из картинки, размер прицела

**Дальность и область**
- отдельные радиусы ломания и удара
- ломание областью N×N с настраиваемой глубиной
- удар по области
- размер персонажа

**Прочее**
- вкладка «Бинды» — свои клавиши, как в ванильном управлении, с подсветкой
  конфликтов
- свои текстуры блоков и предметов прямо из игры
- пресеты настроек в файл `.nvc` вместе с картинками
- команда `/near` — кто рядом, в какой стороне и на каком расстоянии

## Честные ограничения

Мод клиентский, поэтому часть вещей зависит от сервера, а не от него:

- **дальность ломания и удара** проверяет сервер по атрибутам
  `block_interaction_range` и `entity_interaction_range`. В одиночной игре мод
  поднимает их сам, на чужом сервере это может сделать только сам сервер;
- **ломание областью** в выживании на сервере тоже упирается в его проверки;
- **опыт и сытость других игроков** сервер клиентам не присылает вовсе —
  поэтому над головой они показываются только для вас;
- **чанки под свободной камерой** грузит сервер по позиции тела игрока,
  поэтому дальше загруженной зоны будет пустота.

## Сборка

```
./gradlew build
```

Готовый jar — в `build/libs/`. Нужна Java 21.

Мод использует официальные маппинги в рантайме (`reobf = false`), а конфиг
миксинов прописан в манифесте jar (`MixinConfigs`) — в 1.21.4 Forge читает его
только оттуда, строка `[[mixins]]` в `mods.toml` игнорируется.
