# Готовый мод NareVisuals

Сюда кладётся собранный jar и `update.json` — описание, по которому
NareLauncher понимает, что появилась новая версия.

Лаунчер читает `update.json`, сверяет SHA-1 с тем jar, который уже лежит в
сборке, и качает только если файл правда другой. Если GitHub недоступен,
лаунчер молча оставляет то, что стоит, и докладывает встроенный мод.

## Как выложить новую версию

1. Собрать мод: `cd ../forge_narevisuals && ./gradlew build`
2. Скопировать `build/libs/forge_narevisuals-1.0.jar` сюда.
3. Пересчитать контрольную сумму и размер:

   ```
   sha1sum forge_narevisuals-1.0.jar
   stat -c%s forge_narevisuals-1.0.jar
   ```

4. Вписать их в `update.json`, поднять `version`, коротко написать `notes`.
5. Закоммитить и запушить — лаунчер подхватит при следующем запуске игры.

Поле `version` лаунчер показывает человеку, а решает по `sha1`: так не
получится забыть поднять номер и остаться со старым файлом.

## Собранный плагин

`NareServer-1.1.jar` — серверная половина, Paper 1.21.4. SHA-1 `e4dd08f93892759886490c42510780f07b87e1dc`.
Лаунчер его не обновляет: плагин ставится на сервер руками, в `plugins/`.
