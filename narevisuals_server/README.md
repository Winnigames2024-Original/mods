# NareServer

Серверная половина мода [NareVisuals](../forge_narevisuals) — плагин для
**Paper 1.21.4**.

Клиентский мод многого не может в одиночку, и это не лень, а устройство игры:
клиенту некуда отправить что-либо другим клиентам, а дальность ломания и
удара проверяет сервер. Плагин закрывает ровно эти дыры.

## Что добавляет

- **значок «у игрока есть мод»** в списке «Игроки рядом»: клиенты здороваются
  с сервером, сервер рассылает им список своих;
- **честная дальность** ломания и удара — через атрибуты
  `block_interaction_range` и `entity_interaction_range`, только тем, у кого
  есть право `narevisuals.reach`;
- **метки сломанных блоков**: кто-то с модом сломал блок — остальные видят
  метку и могут туда дойти;
- **голосовой чат**: клиенты шлют сжатые кусочки звука, сервер раздаёт их тем,
  кто рядом в том же мире (`voice.distance`, по умолчанию 48 блоков) и у кого
  есть право `narevisuals.voice`;
- **пересылка «шуток»** — и только тем, кто сам их разрешил аргументом запуска
  `--funtrolls2026`. Без этого согласия пакет выбрасывается.

## Установка

```
./gradlew build
```

`build/libs/NareServer-1.0.jar` положить в `plugins/`, перезапустить сервер,
настроить `plugins/NareServer/config.yml`.

По умолчанию дальность не меняется (`reach.blocks: 0`) — включите её сами и
выдайте право `narevisuals.reach` тем, кому можно.

## Протокол

Обычные plugin-сообщения, канал `narevisuals:c2s` от клиента и
`narevisuals:s2c` от сервера. Первый байт — тип пакета.

| → серверу | поля |
|---|---|
| 1 HELLO | int протокол, UTF версия мода, boolean разрешил шутки |
| 2 TROLL | UTF кому, byte какая |
| 6 VOICE | short длина, байты звука (IMA ADPCM, 16 кГц) |

| → клиенту | поля |
|---|---|
| 1 WELCOME | int протокол, double дальность блоков, double дальность существ, boolean шутки разрешены |
| 2 PLAYERS | int сколько, затем UTF имя + boolean разрешил шутки |
| 3 MARK | UTF кто сломал, int x, y, z |
| 4 TROLL | UTF от кого, byte какая |
| 6 VOICE | UTF кто говорит, double x, y, z, short длина, байты звука |
