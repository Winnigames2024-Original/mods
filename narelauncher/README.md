# NareLauncher

Здесь лежит собранный лаунчер и описание свежей версии.

- `NareLauncher.exe` — сам лаунчер
- `NareLauncher.exe.config` — настройки .NET, имя должно совпадать с именем exe
- `update.json` — что сейчас свежее: версия, адрес, контрольная сумма

`update.exe`, который ставится рядом с лаунчером, читает `update.json` при
каждом запуске. Версия в файле новее установленной — качает и подменяет, иначе
просто запускает игру. Нет интернета — тоже просто запускает.

Версия сравнивается по числам, так что `1.10` новее `1.9`.
