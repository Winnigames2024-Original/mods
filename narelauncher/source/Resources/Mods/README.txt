Встроенные моды для сборки "Forge Visuals"
==========================================

Положите сюда .jar мода. Любой файл .jar из этой папки:

  1) встраивается прямо в NareLauncher.exe при сборке проекта
     (в .csproj стоит <EmbeddedResource Include="Resources\Mods\*.jar" />,
      так что перечислять файлы вручную не нужно);

  2) при установке сборки "Forge Visuals" распаковывается в
     %APPDATA%\.minecraft\instances\<версия>-ForgeVisuals\mods

Если exe собран без встроенных модов, лаунчер поищет .jar в папке
Resources\Mods рядом с самим exe — удобно, чтобы подменить мод
без пересборки проекта.

Обычные сборки Forge этот мод не получают: у Forge Visuals отдельный
профиль версии и, значит, отдельная папка модов.
