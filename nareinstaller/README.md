# NareInstaller

Один .exe, который ставит NareLauncher на компьютер: кладёт его в папку, создаёт
ярлыки на рабочем столе и в меню «Пуск» и добавляет рядом `update.exe` —
автообновление лаунчера.

**Скачать:** [NareInstaller.exe](https://raw.githubusercontent.com/Winnigames2024-Original/mods/main/nareinstaller/NareInstaller.exe)

## Два режима

- **Онлайн** — скачивает свежий лаунчер с этого репозитория.
- **Оффлайн** — ставит ту версию, что зашита внутрь самого установщика.
  Пригодится, когда интернета нет или GitHub недоступен.

## Куда ставит

По умолчанию `%LOCALAPPDATA%\Programs\NareLauncher`. Папку можно поменять в
самом окне установщика. Запускать от администратора не нужно.

Ничего, кроме своей папки и ярлыков, установщик не трогает; удалить можно
через «Установка и удаление программ».
